# M2.1 验收报告

2026-11-20，Windows 11 x64，Node 24.16.0，pnpm 11.28.5，Electron 45.4.1，LabScope 0.1.0-m2.1。使用本机已获准的测试环境，Windows 安全策略未改动。

| 验收项 | 结果 | 证据 |
| --- | --- | --- |
| 工程构建与类型检查 | 通过 | `pnpm -r build`、`pnpm -r typecheck` |
| M0/M1 回归 | 通过 | 保留并通过 45 个原有单元测试及 8 项 Electron 主进程/Preload 替身测试。63 个 M0 相关原文件的 SHA-256 与历史清单匹配。 |
| 注册、注销和存储校验 | 通过 | 新增 10 个单元测试覆盖三种内置定义、重复类型、注销、多源订阅生命周期、分屏、移动、配置、限额和损坏布局恢复。 |
| 横纵分屏、尺寸与拖动 | 通过 | 打包后的 Electron 验证实际界面右分、下分、分隔条方向键调整，以及 DOM DragEvent 与 DataTransfer 触发的换位。 |
| 三个面板同时打开 | 通过 | 同一真实窗口打开 Viewer3D、CameraViewer 和 Plot。Viewer3D 绑定点云，Plot 绑定 IMU，CameraViewer 可以选择历史源。 |
| 同源合并和退订 | 通过 | WebSocket 夹具实际收到协议层的 unsubscribe。M1 手动订阅保留。真实窗口关闭独占点云话题的面板后，Worker 订阅列表仅余 IMU，重开后成功重新绑定。 |
| 回放共用消息接口 | 通过 | 单元测试使用相同 envelope，独立 Renderer 夹具用 PlaybackFeed 让 Plot 收到回放帧，seek 清除后可以继续接收。 |
| 重启恢复 | 通过 | 两个独立 Electron 进程使用同一个临时用户配置，第一个保存三个面板和分屏，第二个读出同一份 JSON，并重新建立各自的实时订阅。 |
| 面板异常隔离 | 通过 | 真实 Electron 夹具中的 FaultFixture 故意抛出 render 异常。错误回退显示，故障面板释放实时绑定，相邻的回放 Plot 恢复与更新继续成功，注销后释放剩余帧。 |
| WSL2 Bridge 冒烟 | 通过 | 打包后的 Electron 完成真实 Bridge 握手、两类话题发现、IPC、解码并断开，零采样解码错误。 |
| 完整 Viewer 与文件回放 | 本阶段范围外 | 三个 Viewer 仅提供类型注册和数据绑定预览。PlaybackFeed 使用测试帧，M2.1 没有内置回放文件读取及播放控制。 |

## 复现命令

```powershell
pnpm -r build
pnpm -r typecheck
pnpm test
pnpm test:runtime
pnpm test:integration '`builds-root`\m2.1\win-unpacked\LabScope.exe'
pnpm test:panel-ui '<本机 Electron 45 开发运行时的 electron.exe>'
```

`test:integration` 可省略可执行文件，仅运行 Worker 与环回 Foxglove 夹具。给出解包应用路径会追加原生 Electron 双进程测试。错误隔离夹具使用官方 Electron 开发运行时和临时沙箱窗口，测试视图不会打包到产品。
