# M2.2.2 点云渲染性能

## 环境与负载

2026-11-21，北京时间。Windows 11 x64 build 26200，Intel Core i7-14650HX，NVIDIA GeForce RTX 4060 Laptop GPU（驱动 32.0.15.6624）。Windows 解包开发版使用 Electron 45.4.1、Three.js 0.187.0 和 ANGLE Direct3D11 WebGL2。可见测试窗口使用 1607 × 453 的绘制缓冲区。通过 WebGL 帧缓冲读回验证 10,350 个点颜色像素。

性能组使用 Static Room、种子 42、1× 逻辑时钟、10 Hz 名义点云采样、单可见图层、Height 着色、2 CSS px 点大小。每组绘制该档的全量点云。三图层功能使用三个 10k Topic 独立验收，合计提交 30k 点。初次隐藏窗口被 Chromium 将绘制节流至约 1 FPS，正式数据来自可见窗口重测。

CPU 解码是对模拟源已反序列化消息的字段和布局校验。CPU 处理包括 XYZ 读取、抽样、无效点过滤和颜色计算。WebGL 上传提交是运行 `bufferData` 或 `bufferSubData` 的 Renderer 主线程耗时。GPU 上传查询用 `EXT_disjoint_timer_query_webgl2` 包围上传命令，驱动返回接近零的结果。该值反映查询窗口，D3D11/ANGLE 的延后传输和 staging 拷贝耗时无法单独从这里确认。数据生产测量 Simulator 实际生成数据的 `advance()` 步，独立于 Viewer。30 FPS 目标依据 Electron 绘制帧计数。[Khronos WebGL2 Timer Query](https://registry.khronos.org/webgl/extensions/EXT_disjoint_timer_query_webgl2/)

## 队列与内存

三图层时观察到全程队列峰值 3，每层一个槽。四个短时单层组内显示侧丢弃增量均为 0。10k、50k、100k、500k 的 CPU / GPU 显式缓冲峰值分别为 0.23 / 0.15、1.14 / 0.76、2.29 / 1.53、11.44 / 7.63 MiB。每一档预热后容量分配计数保持不变。500k 组的 Renderer 工作集从 206.0 MiB 到 193.8 MiB，观察峰值 207.9 MiB。

100k 点持续 300.02 秒后关闭成功。596 个采样窗口记录 48,275 次绘制，处理了 3,000 条点云，显示丢弃增量为 0。该组沿用前一组的 500k 容量，CPU / GPU 显式缓冲维持在 11.44 / 7.63 MiB，扩容计数在测量期间没有增加。

Renderer 进程工作集为 173.4 → 峰值 196.6 → 结束 191.0 MiB，GPU 进程为 134.7 → 143.2 → 126.6 MiB，单位均为 MiB。Chromium 报告的粗粒度 JS 堆读数为 9.5 MiB。工作集包含 Chromium 和驱动分配，五分钟测试提供观测基线，长期增长趋势留到 M2.2.6 测量。

## 复现

```powershell
pnpm test:pointcloud-ui '`builds-root`\m2.2.2\win-unpacked\LabScope.exe' 300
```

逐窗口指标、真实绘制设备和进程工作集采样保存在 ``logs-root`\tests\m2-2-2-pointcloud-ui-visible.log`。报告仅覆盖模拟负载，30 分钟全链路稳定性属于 M2.2.6。
