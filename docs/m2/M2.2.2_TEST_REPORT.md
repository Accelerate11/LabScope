# M2.2.2 PointCloud Renderer 测试报告

2026-11-21，北京时间。Windows 11 x64 build 26200，Electron 45.4.1。正式工程为 ``repo-root``。Windows 解包开发构建为 ``builds-root`\m2.2.2\win-unpacked\LabScope.exe`，未签名。沿用本机 Windows 安全策略。

| 用例 | 结果 | 证据 |

| Intensity、RGB、RGBA、Height、Distance | 通过 | 比较强度和几何色值边界，验证 packed FLOAT32、UINT32 与 UINT8 向量解包、Alpha 和字段缺失回退。 |
| NaN、Infinity、无效 Schema | 通过 | 过滤异常坐标，拒绝非法偏移、字段数、重复字段、无效行和截断数据。缺少 XYZ 产生明确错误。 |
| 点数限制、确定性采样和原始数据 | 通过 | 核对均匀、按序的索引和输入字节不变。检查 CPU 缓冲复用。 |
| 多 Topic、独立配置、GPU Buffer 更新 | 通过 | Windows 解包版用真实 WebGL2 绘制三路 10k 点云，切换单层着色/可见性/限点，30k → 21k → 20k → 10k。原图层多次上传后容量分配计数仍为 1。 |
| 清除、图层撤销、Viewer 关闭 | 通过 | Windows 解包版归零绘制范围与原时间戳，退出后查到画布解绑且 WebGL 上下文已释放。独立 Electron 夹具同时检查三个源均退订。 |
| 实时和回放统一接口 | 通过 | 独立 Electron 夹具将同一模拟帧经模拟、实时适配器和 PlaybackFeed 发布到现有总线，同时绘制 30k 点。覆盖跨坐标系隔离、坏帧清空、有效帧恢复、回放 seek 和同帧突发覆盖。 |

| 真实硬件传感器 | 未执行 | 本轮使用模拟源和已捕获的回归夹具。 |

构建、TypeScript 检查、89 项自动化测试和 8 项运行时测试已通过。89 项包括既有 75 项及本阶段新增 14 项。63 个 M0 基线文件中，只有 `packages/ros-schema/src/pointcloud.ts` 使用新布局解析器的预期修改。M0 原始数据、测试及 ROS 2 协议文件通过哈希核对。

## 复现

```powershell
pnpm build
pnpm typecheck
pnpm test
pnpm test:runtime
pnpm test:integration '`builds-root`\m2.2.2\win-unpacked\LabScope.exe'
pnpm test:simulation-ui '`builds-root`\m2.2.2\win-unpacked\LabScope.exe'
pnpm test:pointcloud-ui '`builds-root`\m2.2.2\win-unpacked\LabScope.exe' 300
pnpm test:pointcloud-fixture '<Electron 45.4.1 开发运行时的 electron.exe>'
pnpm test:panel-ui '<Electron 45.4.1 开发运行时的 electron.exe>'
```

原始证据位于 ``logs-root`\tests`，包括 `m2-2-2-verification.log`、`m2-2-2-electron-final.log`、`m2-2-2-electron-fixture-final.log` 和 `m2-2-2-pointcloud-ui-visible.log`。5 分钟实测完成后只修订了主进程回归脚本的断言，最终重新打包沿用同一 Renderer 资源。[点云 API](POINTCLOUD_API.md) · [渲染性能报告](M2.2.2_PERFORMANCE_REPORT.md)
