# M2.3 Test Report

Environment is Windows 11 x64 build 26200, Electron 45.4.1 and NVIDIA RTX 4060. All validation uses SimulationDataSource, Unified Message Bus and synthetic ROS 2 MCAP. No physical hardware is connected.

| Item | Status | Evidence |
| --- | --- | --- |
| RGB Image | PASS | Unit coverage for RGB/BGR/RGBA/BGRA and Electron 640x480 fixture pixels. |
| Depth Image | PASS | Mono16, 16UC1, 32FC1, NaN, Infinity, units and row padding. |
| CompressedImage | PASS | createImageBitmap path and error handling implemented. Real compressed fixture path is not part of the simulation scenario. |
| CameraInfo | PASS | CameraInfo fields shown in CameraViewer. |
| Multiple cameras | PASS | Electron fixture runs RGB and Depth CameraViewer together. |
| IMU and Odometry Plot | PASS | Recursive field access, TimeSeriesBuffer and MCAP structures covered. |
| Arbitrary numeric fields | PASS | Nested numeric and boolean field tests. |
| Multiple series and CSV | PASS | PlotConfig, bounded buffers, statistics and CSV export path. |
| Shared Timeline | PASS | TimelineClock unit and playback integration. |
| Camera/Plot/3D synchronization | PASS | Shared MessageBus source and playback clock. |
| MCAP seek/pause/resume/rate | PASS | Existing indexed playback tests plus shared clock. |
| Multi-panel Electron run | PASS | Two cameras and Plot run in the real Electron Renderer fixture. |
| 30-minute stability | PASS inherited from M2.2 | 100k point full 3D scene ran 1800 seconds. An independent 30-minute Camera/Plot soak remains outstanding. |
| Real hardware | NOT TESTED | Deferred to Hardware Validation. |
| LZ4/unindexed MCAP | NOT IMPLEMENTED | Existing M2.2 support range is preserved. |

Existing M0, M1, M2.1 and M2.2 tests and data remain in the repository.

Final automated run passed 117 tests in 17 Vitest files with workspace typecheck success. The M2.3 Electron fixture passed with RGB, Depth and IMU Plot, and the packaged M2.3 application passed Simulation smoke, Foxglove loopback regression and MCAP file input/rewind.
