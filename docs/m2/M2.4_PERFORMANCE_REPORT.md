# M2.4 Performance Report

The recorder uses a bounded 512-message queue by default and writes off the Renderer path in the Electron main process. Segment chunk target is one MiB. Queue depth, high-water, pending bytes, message count and payload bytes are available in RecordingStatus.

Unit tests verify multi-topic write and queue behavior. A 30-minute or 60-minute recording pressure run was not executed in this iteration. Compression CPU cost, disk throughput, seek latency on large files and disk-full behavior remain NOT TESTED.

Zstd and LZ4 playback support are not extended by M2.4. The writer intentionally rejects those modes instead of silently changing the requested format.
