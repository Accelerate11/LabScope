# Viewer3D 使用指南

## 打开完整模拟场景

1. 启动 LabScope，进入「实时 → 可视化工作区」。
2. 展开「模拟数据」，选择 Moving Robot 或 Obstacle Scene。默认种子 42。需要三路点云时勾选「三路点云」。
3. 点击「启动完整 3D 场景」。工作区创建或复用模拟 Viewer3D，初始 Fixed Frame 为 `map`，显示房间点云、机器人、轨迹、TF 树和 Marker。
4. 在「点云图层配置」添加 `/points/structure` 和 `/points/objects`，分别调整颜色、显示名、大小、上限及采样。
5. 在「场景显示与 TF 树」控制坐标轴、Pose、Odometry、轨迹、Marker 和各话题。轨迹可按颜色、长度（米）、最大点数及采样间隔独立设置。

停止模拟会保留最后一帧，重置清除整套模拟场景。默认场景 Static Room 的机器人保持静止，Moving Robot 有连续轨迹，Obstacle Scene 加入障碍和移动目标，Noisy Sensor 含传感器噪声和可控故障。

## 相机与参考系

| 操作 | 输入 |
| --- | --- |
| 旋转 | 左键拖动 |
| 平移 | 右键拖动，或画布聚焦后的方向键 |
| 缩放 | 滚轮 |
| 聚焦 | 双击画布、工具栏按钮或 F |
| 重置 | 工具栏按钮或 R |
| 顶、底、前、后、左、右 | 标准视角下拉框或数字键 1～6 |
| 透视、正交 | 投影下拉框或 P |

固定参考系可选 map、odom、base_link 或 TF 树中的其它坐标系。源帧和采样时间保持原样。坐标转换失败时，图层行显示原因。选用「点云原坐标系」时，点云按原坐标显示，同名坐标系可叠加。位姿、轨迹和 Marker 仍需可解析的参考系。相机状态随工作区布局恢复。[TF 诊断](TF_ENGINE.md)

## 打开本地 MCAP

在「回放」，或「实时 → 可视化工作区 → 本地 MCAP」，选择支持的 ROS 2 MCAP 文件。点击「播放」开始，使用时间滑块或「回到开头」重建对应时刻的场景。拖动后停在所选时刻，点击播放继续。暂停阶段保持当前画面和 Marker 生命周期。

本次合成示例位于 ``data-root`\simulation\M2.2-moving-robot-seed42.mcap`，使用 Moving Robot 和种子 42，含点云、位姿、轨迹、TF 和 Marker。它的持续时间约一秒，用于验证读档和三维联动。支持索引化的无压缩和 Zstd MCAP。缺索引、其余压缩算法及未提供 ROS 2 Schema 的文件显示诊断。
