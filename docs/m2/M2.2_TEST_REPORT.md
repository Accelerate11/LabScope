## 仅由单元用例覆盖的边界

TF 父节点冲突、循环、断开分支、超缓存时间及精确四元数计算使用纯数据用例。Zstd 索引读由单元用例验证。Windows GPU 路径使用无压缩索引 MCAP 与模拟源。对照 63 项 M0 文件基线，只有 M2.2.2 已验收的 PointCloud2 解码适配修改，原数据及夹具保持哈希一致。
