# M2.3 Performance Report

The Windows Electron fixture runs 640x480 RGB, 640x480 Depth and IMU Plot at the same time. It verifies non-empty Canvas pixels, depth output and more than 100 IMU samples in the SVG Plot.

| Load | Result |
| --- | --- |
| RGB 640x480 | Electron Renderer pass |
| Depth 640x480 | Electron Renderer pass with valid/invalid depth counts |
| IMU Plot | Electron Renderer pass with statistics and SVG series |
| TimeSeries 1M capacity | Bounded buffer and Min-Max downsampling unit pass |
| Two cameras plus Plot | Electron Renderer pass |
| GPU texture upload | NOT SEPARATELY MEASURED. Canvas browser upload has no portable timer in this environment. |

Image decode and Canvas conversion are CPU-side. Plot buffers are bounded and downsampled by Min-Max buckets. M2.2 provides the measured 100k point 30-minute baseline at 159.77 FPS with no display-drop increase. A dedicated 30-minute Camera/Plot soak remains for the next hardware-validation cycle.

The final Windows package is D:/LabScope/builds/development/m2.3/win-unpacked/LabScope.exe. The package is unsigned by project policy.
