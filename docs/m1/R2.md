# M1-R2 运行验收

LabScope Desktop 0.1.0-m1.2。Windows 11 x64 本机运行已由开发者授权，Windows 安全策略保持原样。

| 项目 | 结果 |
| --- | --- |
| 生产入口 | 打包态固定加载包内 Renderer，开发环境限定 HTTP(S) 与开发服务器同源导航。替身和打包态真实冒烟验证通过。 |
| 配置保存 | 同目录临时文件加替换，成功后更新缓存。显式保存失败由 IPC 返回错误，连接过程可继续并记录警告。负责读写和故障反馈的替身测试通过。 |
| 退出 | 正常退出等待 Worker 结束；重复退出共用一次终止，退出期间拒绝创建新 Worker。替身测试已验证等待顺序。 |
| Electron Fuses | Windows 二进制已核对：RunAsNode、Node options 环境变量和 Inspector CLI 关闭，嵌入 ASAR 校验和只从 ASAR 装载开启。 |
| Windows 运行 | 未签名解包版完成 WSL2 Bridge 真实 Electron 冒烟，连接、两种传感器预览、IPC、解码和断开通过。用本地捕获数据的集成测试再次通过。 |
| Windows NSIS | 未签名 x64 安装包构建成功。在本机做了当前用户静默安装、安装后的真实 Electron 冒烟和卸载。 |
| Linux x64 | WSL2 内完成 AppImage 与 deb 构建。解包版连接 WSL2 Bridge 的真实 Electron 冒烟通过，deb 元数据确认为 amd64。WSLg 会话缺少部分 D-Bus 服务，日志有告警。 |
| 测试 | 原有 45 个单元测试保留并通过。新增 8 个桌面运行时替身检查，以及 Worker 和可选 Electron 的集成测试。 |

后续 M2 候选包的冒烟走正常窗口关闭流程，退出码为 0，检查未发现候选包进程残留。持续连接期间关闭、设置跨真实进程重启保留、覆盖升级和断网恢复仍需专门验收。公开发布见 [源码构建与发布](../development.md) 与 [第三方许可证](../third-party-licenses.md)。
