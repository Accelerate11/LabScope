# LabScope V1 User Guide

1. Open Live and connect a Foxglove ROS 2 Bridge, or expand Simulation data.
2. Add Viewer3D, CameraViewer and Plot panels in the workspace.
3. Use Data Center to select topics and start a recording. Pause, resume and stop from the recording controls.
4. Open Playback and choose an indexed ROS 2 MCAP. Use the shared play, pause, rate and seek controls.
5. Open AI Analysis, select an experiment and a configured provider. Local experiment metadata is shown before any provider request.

The current Windows build is unsigned. Real hardware validation is separate from Simulation-First validation.
