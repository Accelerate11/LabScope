# License Candidate Analysis

| Candidate | Strengths | Concerns for LabScope | Engineering assessment |
| --- | --- | --- | --- |
| Apache-2.0 | Explicit patent grant, commercial use, contribution-friendly, good fit for an extensible robotics project | Requires correct notices and attribution. Final ownership must be confirmed | RECOMMENDED CANDIDATE, not selected |
| MIT | Very simple and permissive | Weaker explicit patent language and less structured notice practice | Viable alternative |
| BSD-3-Clause | Permissive with non-endorsement clause | Similar patent/notice considerations to MIT | Viable alternative |
| MPL-2.0 | File-level copyleft and patent terms | More obligations for modified covered files and future plugin boundaries | Less aligned with the current permissive product goal |

Apache-2.0 is the strongest engineering candidate for university, company, and community use, but the project maintainer and all relevant contributors must confirm source ownership and the final choice. No formal license file was created by this audit.
