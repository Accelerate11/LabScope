# License status

The original LabScope source license has not been formally selected. Apache-2.0 is a candidate and is not a grant of rights until the maintainers confirm source ownership and publish the final license notice.

This repository therefore does not include a formal `LICENSE` file yet. The absence of that file is intentional.

Third-party dependencies retain their own licenses. See [docs/third-party-licenses.md](docs/third-party-licenses.md) for the current inventory and remaining review items. The inventory is an engineering review and does not replace legal confirmation.

Open items before selecting a final license:

- Confirm copyright and contribution ownership for the original source
- Verify ROS 2 schema and Foxglove Bridge fixture attribution
- Preserve Electron, Chromium, FFmpeg, and npm dependency notices in distributed packages
- Recheck package contents for each Windows and Linux release
